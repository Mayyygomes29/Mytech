🚀 Novo Projeto Pessoal Finalizado!

Estou animada em compartilhar meu novo projeto pessoal desenvolvido com Python e o framework Django. Essa aplicação web reúne diversas funcionalidades práticas, incluindo integração com API externa, autenticação com JWT e gerenciamento de conteúdo.

🔧 Funcionalidades Implementadas

▪️ Integração com API de Vagas de Emprego: Consumo de API externa para obter vagas de emprego, armazenamento em banco de dados SQLite e gerenciamento de cookies para melhorar a experiência do usuário.

▪️Visualização de Vagas: Criação de views para listar todas as vagas disponíveis e exibir detalhes individuais de cada vaga.

▪️Sistema de Autenticação com JWT: Implementação de login e logout utilizando JSON Web Tokens (JWT), incluindo registro de novos usuários e controle de sessões com blacklist de tokens.

▪️Aplicativo de Notícias: Desenvolvimento de um sistema para criação e gerenciamento de notícias, com armazenamento em banco de dados e visualização detalhada de cada notícia.

🛠️ Tecnologias Utilizadas

Linguagem: Python 🐍
Framework: Django + Django REST Framework
Banco de Dados: SQLite
Autenticação: JWT
Controle de Versão: Git, GitHub

Este projeto me proporcionou uma excelente oportunidade para aprofundar meus conhecimentos em Django, autenticação segura e integração de APIs externas. Estou aberto a feedbacks e sugestões de melhorias!
